Collegamento a GitHub

Indica il repository privato dei conteggi. Il token viene tenuto solo nella sessione di questa scheda e non viene inserito nei file esportati.

Se cambi repository, file o nome inventario, l’app separa i conteggi locali per evitare di mescolare inventari diversi. Il repository deve avere già un branch iniziale.

CERCA CON UNA FOTO

Fotografa il pezzo

Inquadra un solo pezzo su uno sfondo chiaro, con buona luce. Ti mostriamo le famiglie più simili: scegli poi misura e variante.

Caricamento dell’indice fotografico…

La foto viene elaborata sul dispositivo. Al primo utilizzo si scarica un modello di circa 90 MB: usa il Wi-Fi. Gli scatti non vengono caricati su GitHub.

Preparazione delle foto del catalogo

Da fare una volta, preferibilmente su PC. Prepara l’indice dalle immagini pubblicate, oppure dalla cartella selezionata nelle Impostazioni. Puoi interrompere e riprendere. Gli altri telefoni possono importare lo stesso indice.

Per distribuirlo automaticamente, carica il file esportato nel repository dell’app come data/photo-index.json. Servono anche le foto in images/ per visualizzare le proposte.
